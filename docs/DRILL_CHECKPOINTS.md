# Drill Checkpoints

## Overview

Each drill is divided into smaller sections called **checkpoints**. When a student completes a checkpoint, their progress is saved automatically. They can continue immediately or exit and return later, picking up exactly where they left off. A drill is only marked complete when all checkpoints are finished.

## Checkpoint Structure by Drill Type

| Drill Type | Checkpoint Structure |
|---|---|
| Vocabulary | Every 5 items |
| Pronunciation | Every 5 items |
| Roleplay | By scene |
| Matching | Every 5 items |
| Definition | Every 5 items |
| Grammar | Every 5 items |
| Sentence Writing | Every 5 items |
| Filling in the Blank | Every 5 items |
| Key Phrases | Every 5 items |
| Summary | No checkpoints — completed in one sitting |

## Flow

1. Student opens a drill and completes the first 5 items
2. A checkpoint screen confirms progress is saved
3. Student can continue to the next section or exit
4. On return, the drill reopens at the next uncompleted section
5. Drill is marked complete only when all sections are finished
